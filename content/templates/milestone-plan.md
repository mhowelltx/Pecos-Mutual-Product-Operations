## Purpose

Use this plan in Planning to break a prioritized project into goals and milestones the team can deliver within about 3 months.

## The template

Copy the block below into your project space.

```markdown
# Milestone plan: <project name>

**Project Manager:** <name>  ·  **Product Owner:** <name>  ·  **Horizon:** <start> to <end>

## Goals
1. <outcome the business will see>

## Milestones
| # | Milestone | Done when | Target date | Owner |
| - | --------- | --------- | ----------- | ----- |
| 1 |           |           |             |       |

## Risks and dependencies
- <risk>: <mitigation>
```
