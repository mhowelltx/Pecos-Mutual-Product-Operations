# Button

Square, all-caps call-to-action buttons; three variants that follow the ground they sit on.

- **Provide:** an `<a>` or `<button>` with `pm-btn` plus one variant, and a short verb label (2–3 words).
- `pm-btn--gold` — 1px `gold` outline + gold label on `midnight` only. Hover fills `gold`, label turns `midnight`. Primary action in mastheads and dark sections.
- `pm-btn--white` — `midnight` fill, white 1px border and label; secondary next to a gold button. Hover → `sky`.
- `pm-btn--dark` — solid `midnight`, no border, white label, on white or `surface-alt`. Hover → `sky` with `midnight` label.
- Min width 220px (140px on tablet), padding 20px × 30px, `button` text style, `radius-none`.
- Don't put gold buttons on white (gold on white fails contrast). Don't round the corners.
