# Card

Square, borderless cards in rows of three: a white icon card and a midnight text card.

- **Provide:** the whole card as one link; `pm-card__title` (≤8 words); either an icon from `assets/Icons/` (white card) or a 1–2 sentence `body` paragraph (dark card).
- White icon card (`pm-card`): on `surface-alt`, icon ≤100×80, title in `ink`, padding `space-card`.
- Dark card (`pm-card--dark`): `midnight`, title in `gold`, copy in `body-light`, padding 90px × 33px on desktop.
- Hover: `shadow-card-hover`, icon and title lift 8px. Gutter `space-small`.
- Never round corners or add coloured side borders.
