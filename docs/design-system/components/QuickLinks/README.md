- **Provide:** 4–6 links, each an icon from `assets/Icons/` (orange set) + a 2–4 word task label ("Report an Injury", "Make a Payment").
- Bar: `white`, `radius-pill`, 50px side padding, 40px gaps; sits over the bottom of the Masthead or on `surface-alt` (then square, `surface-alt` fill).
- Icons 36×34px. Label `quicklink` style in `black`; hover turns `blue` and grows an `orange` underline from the centre.
- Mobile: square corners, two columns with icon left of label.
