# SectionHeading

Centred section intro: eyebrow, serif H2 and the gold-star hairline divider.

- **Provide:** an `eyebrow` (2–3 words, sentence case), an `h2` (one sentence, sentence case, no period), optionally a `body` paragraph, then `.pm-divider`.
- Divider: a `gold` 21×20 five-point star between two 1px `rule` lines up to 216px each.
- Max width 800px, 24px gaps, 30px vertical padding.
- Left-aligned H2s (no eyebrow, no star) introduce 2-column text+image sections.
