# Masthead

Full-bleed `midnight` hero: headline left, documentary photo right fading into the dark, quick-link bar overlapping the bottom.

- **Provide:** an ALL-CAPS `h1` of 2–4 short lines with the last line wrapped in `.pm-hl` (renders `gold`); one `body` paragraph in `body-light`; a `pm-btn--gold` primary + `pm-btn--white` secondary; a photo.
- Photo: real workers on the job (warehouse, welding, trades, small shops), placed in `.pm-masthead__photo` at 70% width with a left-to-right `midnight` fade (22% → 54%). The preview shows a striped placeholder.
- Padding `space-masthead` top; copy column ≤600px (paragraph ≤440px).
- Interior pages reuse it with a shorter headline ("JUST FOR / EMPLOYERS") and one sentence.
- On mobile the photo stacks above the copy at 320px tall with no fade.
