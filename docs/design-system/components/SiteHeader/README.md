- **Provide:** the logo (`assets/Logos/pecos-mutual-logo.svg`), the audience links ("Just for:" Agents, Health Care Providers, Injured Employees), 3 primary nav items, and utility items (search, Contact us, Login).

- Rows divided by a 1px `border` rule; utility items are boxed by vertical `border` rules on the right.
- Nav items open mega-menus organised by audience (Employers / Agents / Providers / Injured Employees).
- Keep the header white; never place the logo on a coloured bar here.
