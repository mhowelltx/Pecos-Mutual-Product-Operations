# StatCallout

Big-number typographic callout on `midnight`, set between two `body-light` hairlines.

- **Provide:** three short lines — the figure, one verb in `sky`, and a small trailing phrase.
- `stat` style (serif, ALL CAPS); the accent line uses `sky`; trailing line ~60% size.
- Use once per page, paired with an H2 + paragraph + gold button in a dark 2-col section.
- Demo figures should be clearly illustrative; don't reuse a real company's reported numbers.
